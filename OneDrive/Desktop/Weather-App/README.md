# 🌦️ Weather App

A modern, responsive weather application built using **HTML, CSS, and JavaScript** that provides real-time weather information for any city around the world.

![Weather App](https://img.shields.io/badge/HTML-5-orange?logo=html5)
![CSS3](https://img.shields.io/badge/CSS-3-blue?logo=css3)
![JavaScript](https://img.shields.io/badge/JavaScript-ES6-yellow?logo=javascript)
![License](https://img.shields.io/badge/License-MIT-green)

---

## 📖 Overview

This Weather App allows users to search for any city and instantly view current weather conditions including:

- 🌡️ Temperature
- 💧 Humidity
- 🌬️ Wind Speed
- ☁️ Weather Description
- 🌍 City & Country
- 🎯 Real-time Weather Data

The application features a clean, responsive interface that works seamlessly across desktop and mobile devices.

---

## 🚀 Features

- 🔍 Search weather by city name
- 🌡️ Real-time temperature
- 💨 Wind speed information
- 💧 Humidity details
- ☁️ Weather condition icons
- 📱 Fully responsive design
- ⚡ Fast and lightweight
- ❌ Error handling for invalid city names

```bash

```

### Open

Simply open **index.html** in your browser.

---

## 🔑 API Setup

1. Create an account on OpenWeatherMap.
2. Generate your API key.
3. Replace the API key inside `script.js`.

Example:

```javascript
const apiKey = "YOUR_API_KEY";
```
